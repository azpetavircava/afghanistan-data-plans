## 三、APN与网络设置：让手机真正“上网”

　　这可能是最容易被忽略但最关键的一步。你有没有遇到过信号满格，但微信图片怎么也刷不出来的情况？八成是APN没设对。

　　插卡后，手机通常会自动收到配置信息，但有时会失效。这时就需要手动设置：
1.  进入手机“设置” > “移动网络” > “接入点名称（APN）”。
2.  新建一个APN，名称可随意填写（如“MTN Internet”）。
3.  根据你的运营商填写APN信息（这是核心！）：
    -   **MTN**: APN 填写 `mtninternet`
    -   **Roshan**: APN 填写 `internet` (或 `roshan`)
4.  保存并选中这个新建的APN，然后重启手机。

　　看，就这么简单，但能解决90%的上网问题。话说回来，不同手机菜单路径略有差异，但关键词都是“APN”。
